# Админ-панель ТрофиК: запуск на VPS

## Первичная настройка

1. Создайте постоянные папки, не внутри папки очередного релиза:

   ```bash
   sudo install -d -m 750 /var/lib/trofik/uploads
   sudo chown -R <пользователь_приложения>:<группа_приложения> /var/lib/trofik
   ```

2. Скопируйте `.env.example` в `.env` и задайте пути к этим папкам.

3. Создайте пароль. Команда не записывает сам пароль в историю терминала:

   ```bash
   npm run admin:password
   ```

   Вставьте напечатанное значение целиком в `ADMIN_PASSWORD_HASH` файла `.env`. Для ключа сессий используйте `openssl rand -base64 48` и вставьте результат в `ADMIN_SESSION_SECRET`.

4. Не добавляйте `.env`, `/var/lib/trofik` или резервные копии базы в Git.

## Резервная копия

SQLite-база — это один файл `/var/lib/trofik/trofik.sqlite`. Перед обновлением приложения сделайте его копию вместе с фотографиями:

```bash
sudo tar -czf /var/backups/trofik-$(date +%F).tar.gz /var/lib/trofik
```

## Использование

- Вход: `/admin`.
- Логин: `Ekaterina-admin` (можно изменить через `ADMIN_USERNAME`).
- Новая услуга появляется в каталоге сразу после сохранения. Чтобы показать её на главной, включите переключатель «Показывать в блоке „Что мы делаем“».
- Услуги, отзывы и акции можно добавлять, редактировать, скрывать, удалять и перемещать стрелками.
