# План: блок «Наши работы» (мозаика фото) на главной — выполнено

**Цель:** между «Что мы делаем» и «Отзывами» — галерея работ мастеров мозаикой, фото управляются из админки. По нажатию фото открывается на весь экран.

## Как выглядит
- Заголовок в стиле остальных блоков (рукописный «Наши работы», золотая черта), под ним мозаика.
- ПК: сетка 4 колонки, квадратные ячейки, скругление и золотая рамка как у карточек. Плитки трёх размеров — **обычная** (1×1), **широкая** (2×1), **крупная** (2×2); `grid-auto-flow: dense` закрывает дыры.
- Телефон: 2 колонки, крупная — на всю ширину квадратом, широкая — на всю ширину.
- На плитке снизу — подпись (например, «Макияж»), при наведении фото чуть увеличивается.
- По нажатию — просмотр на весь экран (`<dialog>`), листание стрелками/свайпом, закрытие по ×, Esc и фону.

Стартовая раскладка 7 фото (ровно 3 ряда на ПК без пустот):
```
[ макияж  ][ брови ][ресницы]
[ 2×2     ][ до/после  2×1 ]
[ маникюр 2×1 ][ногти][ногти]
```

## Файлы
- `lib/db.js` — таблица `works` (image_path, caption, alt, tile, is_visible, sort_order) + стартовые 7 фото. **Server**
- `lib/content.js` — `getWorks()`. **Server**
- `app/api/admin/content/route.js` — коллекция `works`, проверка `tile`. **Server**
- `components/AdminDashboard.jsx` — раздел «Наши работы»: фото, подпись, «что на фото», размер плитки, показывать/скрыть, порядок стрелками, требования к фото. **Client**
- `components/Works.jsx` + `Works.module.css` — секция с мозаикой, данные из базы. **Server**
- `components/WorksGallery.jsx` — мозаика и просмотр на весь экран. **Client** (отклонение: сетка тоже здесь — плиткам нужны обработчики нажатия; разметка и `<img>` всё равно приходят в HTML с сервера).
- `app/page.jsx` — блок после `ServicesOverview`, внутри `SectionTransitions` перед `Reviews`.
- `public/images/works/*.jpg` — 7 подготовленных фото: повёрнуты по EXIF, ужаты до 1600 px по длинной стороне, у фото ногтей обрезана подпись «REDMI NOTE 13».

## Риски
- Обрезка: плитки квадратные/широкие, поэтому вертикальные фото обрезаются по центру. Для до/после выбрана широкая плитка, чтобы оба лица остались целыми.
- Фото 722–960 px в ширину — на крупной плитке ПК (≈600 px) хватает, для новых в админке укажу минимум 1200 px.
